MyChatbot 🤖

A ChatGPT-style AI chatbot web application built using Flask and Python.

MyChatbot is a web-based AI chatbot that allows users to interact with an AI assistant through a simple chat interface.
The project includes user authentication and a conversational chat interface. It was developed to understand how AI APIs can be integrated into a web application and how a complete chatbot workflow can be built using Flask.

 ✨ Features

- User Sign Up and Sign In
- Secure password handling
- AI-powered conversations
- Chat interface similar to modern AI assistants
- New Chat functionality
- Send messages using the Enter key
- Forgot Password functionality
- SQLite database for user authentication
- Responsive and simple user interface

🛠️ Technologies Used

   Python
   Flask
   SQLite
   HTML
   CSS
   JavaScript
   AI API (Gemini / Groq)
